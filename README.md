# Мини-проект 1: автоматический выключатель света

ESP32-S3 измеряет освещённость фоторезистором и управляет реле: стемнело — реле включает свет, рассвело — выключает. Настройки — в `main/app_config.h`, структура проекта описана в конце.

Что показано:

- oneshot-режим ADC (`esp_adc/adc_oneshot.h`): задача датчика раз в 100 мс читает одно значение через `adc_oneshot_read`;
- настройка GPIO одной структурой `gpio_config_t`, а не по одной функции на свойство;
- две задачи FreeRTOS: датчик опрашивает ADC и при смене решения будит задачу реле уведомлением (`xTaskNotify`);
- гистерезис, чтобы реле не щёлкало на границе порога.

## Схема подключения

| Сигнал | Пин ESP32-S3 |
|---|---|
| Фоторезистор (середина делителя) | GPIO1 (ADC1, канал 0 — как в lesson4) |
| Вход IN модуля реле | GPIO21 |
| Питание модуля реле | VCC → 5V (или 3V3, смотри модуль), GND → GND |

Делитель для фоторезистора:

```
3V3 ── фоторезистор ──┬── резистор 10 кОм ── GND
                      └── GPIO1
```

При такой схеме чем светлее, тем выше напряжение на GPIO1. Если фоторезистор стоит снизу (между средней точкой и GND), поменяй в `main/app_config.h` `IS_HIGHER_VOLTAGE_DARKER` на `true`.

## Пороги

| Константа | Значение | Смысл |
|---|---|---|
| `LIGHT_PERCENT_TURN_ON_THRESHOLD` | 60 % | свет ниже → реле включить |
| `LIGHT_PERCENT_TURN_OFF_THRESHOLD` | 80 % | свет выше → реле выключить |

Между 60 и 80 % состояние реле не меняется — это и есть гистерезис.

Процент считается от калибровочного значения `LIGHT_SENSOR_FULL_LIGHT_RAW_VALUE` (сырое значение ADC при полностью освещённой комнате): `raw / LIGHT_SENSOR_FULL_LIGHT_RAW_VALUE * 100`, выше калибровочного — 100 %. Опрос — раз в 100 мс (`LIGHT_SENSOR_POLL_INTERVAL_MS`), без усреднения.

## Полярность реле

`RELAY_ACTIVE_LEVEL` в `main/app_config.h` — уровень, который включает реле. По умолчанию `0` (большинство модулей active-low). Если реле включается при старте и выключается по команде «включить» — поставь `1`.

## Сборка и прошивка

```bash
cd ~/work/embedded/esp32-mini-project-1
make build     # собрать
make flash     # прошить
make monitor   # смотреть лог (выход: Ctrl+])
make run       # прошить и сразу смотреть
```

Если подключено несколько плат: `make flash PORT=/dev/cu.usbmodemXXXX`. Сменить чип: `make chip CHIP=esp32c3`.

## Что проверить на плате

1. В логе раз в секунду: `raw=... свет=...% реле=...`. Накрой фоторезистор рукой — процент должен упасть. Если растёт — инвертируй `IS_HIGHER_VOLTAGE_DARKER`.
2. При старте реле должно быть выключено. Если включено — инвертируй `RELAY_ACTIVE_LEVEL`.
3. Откалибруй 100 %: при полностью освещённой комнате посмотри `raw=` в логе и запиши это значение в `LIGHT_SENSOR_FULL_LIGHT_RAW_VALUE` в `main/app_config.h` (по умолчанию 3400).
4. Подбери пороги под свою комнату: 60/80 % — отправная точка, реальный диапазон зависит от фоторезистора и резистора в делителе.

## Структура проекта

```
components/
  relay/
    CMakeLists.txt         регистрация компонента реле
    include/relay.h        API реле: relay_config_t, relay_init, relay_set_state
    relay.c                GPIO реле: настройка пина и выставление уровня с учётом полярности
  light_sensor/
    CMakeLists.txt         регистрация компонента датчика света
    include/light_sensor.h API датчика: light_sensor_config_t, light_sensor_init, light_sensor_read
    light_sensor.c         ADC oneshot: настройка канала, чтение и перевод в проценты
main/
  CMakeLists.txt           сборка main с зависимостями от relay и light_sensor
  app_config.h             все настройки: пины, полярность, канал ADC, пороги, интервалы
  main.c                   app_main: инициализация компонентов и запуск задач
  relay_control_task.h/.c  задача реле: ждёт уведомление и переключает реле
  light_sensor_task.h/.c   задача датчика: опрос, повторы при сбое, лог, гистерезис, уведомление задаче реле
```
