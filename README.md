# Мініпроєкт 1: автоматичний вимикач світла

ESP32-S3 вимірює освітленість фоторезистором і керує реле: стемніло — реле вмикає світло, розвиднілося — вимикає. Налаштування — у `main/app_config.h`, структуру проєкту описано наприкінці.

Що показано:

- oneshot-режим ADC (`esp_adc/adc_oneshot.h`): завдання датчика раз на 100 мс читає одне значення через `adc_oneshot_read`;
- налаштування GPIO однією структурою `gpio_config_t`, а не окремою функцією на кожну властивість;
- два завдання FreeRTOS: датчик опитує ADC і при зміні рішення будить завдання реле сповіщенням (`xTaskNotify`);
- гістерезис, щоб реле не клацало на межі порога;
- стійкість до збоїв читання: до 5 невдалих читань поспіль (`LIGHT_SENSOR_MAX_CONSECUTIVE_READ_FAILURES`) завдання повторює спробу, після п'ятого — зупиняється через `ESP_ERROR_CHECK`.

## Схема підключення

| Сигнал | Пін ESP32-S3 |
|---|---|
| Фоторезистор (середина подільника) | GPIO1 (ADC1, канал 0 — як у lesson4) |
| Керування реле (через інвертувальний каскад, див. нижче) | GPIO21 |
| Живлення модуля реле | VCC → окреме джерело 5 В (див. нижче), GND → GND |

Подільник для фоторезистора:

```
3V3 ── фоторезистор ──┬── резистор 10 кОм ── GND
                      └── GPIO1
```

За такої схеми що світліше, то вища напруга на GPIO1. Якщо фоторезистор стоїть знизу (між середньою точкою та GND), зміни в `main/app_config.h` `IS_HIGHER_VOLTAGE_DARKER` на `true`.

Між GPIO21 і входом IN модуля реле стоїть інвертувальний каскад на BC547B: колектор підтягнуто резистором R4 (10 кОм) до 5 В і з'єднано з IN, база — через обмежувальний резистор до GPIO21, емітер — на GND. Модуль реле active-low (усередині PNP-транзистор), тому одиниця на GPIO21 відкриває BC547B, притискає IN до землі й вмикає реле; нуль на GPIO21 — реле вимкнене.

```
GPIO21 ── R(база) ── BC547B (база)
                     BC547B (емітер) ── GND
                     BC547B (колектор) ──┬── R4 10 кОм ── +5 В
                                         └── IN модуля реле
```

Живлення модуля реле краще брати не з піна `5V` плати (на ній стоїть захисний діод, під струмом котушки напруга просідає), а від окремого джерела 5 В зі спільною землею з платою; підтяжка R4 — до цього ж джерела.

## Пороги

| Константа | Значення | Зміст |
|---|---|---|
| `LIGHT_PERCENT_TURN_ON_THRESHOLD` | 60 % | світло нижче → реле ввімкнути |
| `LIGHT_PERCENT_TURN_OFF_THRESHOLD` | 80 % | світло вище → реле вимкнути |

Між 60 і 80 % стан реле не змінюється — це і є гістерезис.

Відсоток обчислюється від калібрувального значення `LIGHT_SENSOR_FULL_LIGHT_RAW_VALUE` (сире значення ADC у повністю освітленій кімнаті): `raw / LIGHT_SENSOR_FULL_LIGHT_RAW_VALUE * 100`, вище за калібрувальне — 100 %. Опитування — раз на 100 мс (`LIGHT_SENSOR_POLL_INTERVAL_MS`), без усереднення.

## Полярність реле

`RELAY_ACTIVE_LEVEL` у `main/app_config.h` — рівень на GPIO21, який вмикає реле. За замовчуванням `1`: через інвертувальний каскад на BC547B одиниця на піні дає нуль на вході IN модуля active-low. Якщо підключити IN модуля до GPIO21 напряму, без каскаду, — постав `0`. Ознака неправильної полярності: реле вмикається при старті й вимикається за командою «ввімкнути».

## Збірка та прошивка

```bash
cd ~/work/embedded/esp32-mini-project-1
make build     # зібрати
make flash     # прошити
make monitor   # дивитися лог (вихід: Ctrl+])
make run       # прошити й одразу дивитися
```

Якщо підключено кілька плат: `make flash PORT=/dev/cu.usbmodemXXXX`. Змінити чип: `make chip CHIP=esp32c3`.

## Що перевірити на платі

1. У лозі раз на секунду: `raw=... свет=...% реле=...`. Накрий фоторезистор рукою — відсоток має впасти. Якщо зростає — інвертуй `IS_HIGHER_VOLTAGE_DARKER`.
2. При старті реле має бути вимкнене. Якщо ввімкнене — інвертуй `RELAY_ACTIVE_LEVEL`.
3. Відкалібруй 100 %: у повністю освітленій кімнаті подивися `raw=` у лозі й запиши це значення в `LIGHT_SENSOR_FULL_LIGHT_RAW_VALUE` у `main/app_config.h` (за замовчуванням 3400).
4. Добери пороги під свою кімнату: 60/80 % — відправна точка, реальний діапазон залежить від фоторезистора та резистора в подільнику.

## Структура проєкту

```
components/
  relay/
    CMakeLists.txt         реєстрація компонента реле
    include/relay.h        API реле: relay_config_t, relay_init, relay_set_state
    relay.c                GPIO реле: налаштування піна і виставлення рівня з урахуванням полярності
  light_sensor/
    CMakeLists.txt         реєстрація компонента датчика світла
    include/light_sensor.h API датчика: light_sensor_config_t, light_sensor_init, light_sensor_read
    light_sensor.c         ADC oneshot: налаштування каналу, читання і переведення у відсотки
main/
  CMakeLists.txt           збірка main із залежностями від relay та light_sensor
  app_config.h             усі налаштування: піни, полярність, канал ADC, пороги, інтервали
  main.c                   app_main: ініціалізація компонентів і запуск завдань
  relay_control_task.h/.c  завдання реле: чекає сповіщення і перемикає реле
  light_sensor_task.h/.c   завдання датчика: опитування, повтори при збої, лог, гістерезис, сповіщення завданню реле
```
